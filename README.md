# ParkRadar

Know before you park. A campus parking app with enforcement reports, lot availability, zone rules and walking directions.

## What's here

- `index.html` is the public front page at https://parkradarapp.com/. Until ParkRadar is released it is a "coming soon" page, and the web app is held back and published at launch.
- `privacy.html`, `terms.html`, `cookies.html`, `refunds.html` and `about.html` are ParkRadar's policy pages.
- `manifest.webmanifest`, the icons and `CNAME` are the site's supporting files.

It is hosted with GitHub Pages. Reports and lot updates are shared through Firebase between the website and the ParkRadar iPhone app.
